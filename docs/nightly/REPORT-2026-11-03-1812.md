## 2. What failed and why

Nothing in any gate at the end. On the way:

**The shell kills background work.** `gates.py` was first written to run end to end, about fifteen minutes with the fourteen perfect-play solves. The night shift's shell ends every process when a call returns, `nohup` and `setsid` included, and a call lasts 180 seconds at most, so the whole gate cannot run in one piece here. It now runs in parts (`--part bands5`, `--part solve-sky-15`, ...) that each fit a call, saving under `results/parts/<engine>/`, and `--assemble` builds the table. With no flag it still runs everything inline on a machine without the limit. The README says which parts fit together in one call.

**The repo is `"type": "module"`.** `agents_ref.js` could not `require` the August engine (an ES-module scope), and renamed `.cjs` it still could not, because the engine itself was then loaded as ESM and exported nothing. The script reads the engine's source and runs it by hand as CommonJS. Nothing in `base/` changed.

**The ledger's first pass** flagged a heading's first word, "Twenty-eight" as "Twenty", and the names of languages and people in a README. It now matches at a line start only after a lower-case article, skips a word followed by a hyphen, treats common proper nouns of the work (Python, Justin, Claude, the Swiss Ephemeris) as free, and skips README files, which an engineer reads.

**Node and Python versions** are the Cowork VM's, not the Mac's own shell; the Mac's shell is not reachable from here. Stated as such in both places they are recorded.

Choices made rather than asked:

- Five packets in one run, for the reason above.
- The bands' configuration is the fixed port's (`research/manzil-v6-conformance.md` section 2), with the chart five in the build's order `[6,10,17,18,5]`, since hand order moves the number by eleven points; the pack's own `v6run.py` (the earlier, bad-port harness, 60.1 / 45.1) is kept in `base/` and not used.
- The scan and the solve use the friend-build table from `research/manzil-why-storm3.md` (chart five at level 2, the rest loaned and silent), the configuration that gave the six and the 7/7.
- The baseline's band rows are INFO, not FAIL, so the runner's own gate (reproduce v1) can be green while the engine's bands are red, which is the known state.
- The ledger counts the 28 epithets only in their capitalised form; in the house style "the gate" lower case is English as often as it is the card.
- `vectors_agents.json` is committed as data so the Python gate runs without node; `agents_ref.cjs` regenerates it if the reference ever changes.
