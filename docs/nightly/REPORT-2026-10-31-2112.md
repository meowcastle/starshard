## 2. What failed and why

Nothing in the gate failed. Three things could not be done the straight way, and what was done instead:

**No browser on the Mac's VM.** `npx playwright install chromium` is refused by the network allowlist (403 "Connection blocked by network allowlist" from cdn.playwright.dev and from the Microsoft mirror). The smoke therefore ran in the sandbox against a byte-identical build, as above. On the Mac itself, `npx playwright install chromium` once and `node test/smoke-app.mjs` runs strict, fonts included.

**The build command.** The root `package.json` is outside the night shift's write list, so the gate's `npm run build:app` lives in `app/package.json` and runs as `npm --prefix app run build:app` from the root (or `npm run build:app` inside `app/`). If Justin wants the root alias exactly as the gate names it, it is one line in the root manifest: `"build:app": "npm --prefix app run build:app"`. Same for `dist/`: the brief says "built to `dist/`" without saying where; the write list has no root `dist/`, so the build writes `app/dist/`. `tools/deploy.sh` (SS12) will ship from there. `app/dist/` should join `.gitignore` (root file, Justin's one line).

**The design canvas is not in the repo.** The "Star Shard Web App" canvas with its fourteen boards exists only in the Design tool; nothing under `design/`, `_incoming/` or the docs carries an export. The shell was built to STARSHARD-LAUNCH §2.2 and §2.3, APP-FRAMEWORK.md, and the V2 game file's own values, which §0 ranks above the boards anyway. When the canvas is exported into the repo, the next shell packet checks the chrome against it.

Choices made rather than asked:

- **The five tabs are tonight · your chart · your shard · codex · play.** Home is reached from the brand mark on a phone and account from the chip; APP-FRAMEWORK's rule "never name a tab Home" decided which five. Pre-tested at 390 px: five 44 px targets fit with the labels at 11 px. If Justin would rather have home in the bar and drop play (the game is landscape and opens as its own page), it is a one-flag change in `routes.mjs`.
- **Radius.** The V2 game's buttons and panels carry a 5 px radius; DESIGN-SYSTEM's "radius zero" sits in its §3, which the task prompt retires except for spacing. The shell follows the game: 5 px on buttons and inputs, round chips. SS3's legal pages used radius 0 and still do.
- **No starfield, no scene.** The scaffold's ground is the game's radial night and its own grain tile (the `.mzGrain` data URI, at the game's .055 overlay). The lamp-lit horizon scene and the hour lighting are SS5's, lifted from the V2 file then; drawing a stand-in now would break §0 rule 1.
- **The icons are the game's.** The tab bar reuses the V2 pause menu's buttons (the dashed 44 px ring, the book for codex, the two cards for play, the constellation for the shard, the house for home); tonight and the chart use the ☾ and ☉ glyphs the brief names. No icon was drawn new; the signed-out chip shows an empty ring and the words "sign in", and the signed-in chip shows the first letter of the name until the avatar system is ported.
- **The account chip does not call the API on localhost.** `api.js` points at `https://api.<hostname>`, which does not exist for a local static server; the chip shows "sign in" without a network call there. On any other host it calls `api.me()` once and shows the name.
- **Station ranges read "0°00′ Aries to 12°51′ Aries".** `stations.js` writes the range with a spaced en dash, which the lint (and WRITING.md) refuse on a visitor's surface; the build writes "to" into the index. The corpus file is untouched.
- **Privacy and terms stay SS3's static pages**, copied into `dist/` and linked as full pages. They have their own chrome; the shell's `/privacy` and `/terms` routes are those files, not React pages. The two look the same (same tokens) and SS11's accessibility pass can decide whether they should sit inside the shell.
- **Placeholders.** Each route renders its archetype's header (eyebrow, title, one line from the route table) and its doors, in the game's type on the game's ground, and nothing invented beyond that. The codex and station pages are real: the index of 28 from `stations.js`, previous and next on each station page, a not-found for an unknown slug. SS5 to SS9 fill the bodies.

Vocabulary on every visitor surface: star shard, tonight, your chart, your shard, codex, play, station, sign in, sign up, account. "Mansion" appears nowhere; no new noun.
